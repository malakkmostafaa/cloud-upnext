# UpNext — Mini-Jira on AWS

> A lightweight team task-management web application built on AWS, supporting multiple teams with role-based access, event-driven notifications, and high-availability deployment.

## ☁️ AWS Services

| Service | Role in the System |
|---------|-------------------|
| EC2 (Auto Scaling Group) | Hosts the Node.js backend across 2 Availability Zones |
| Application Load Balancer | Distributes traffic across EC2 instances and runs health checks |
| CloudFront | CDN in front of the ALB for low-latency delivery of the app and static assets |
| DynamoDB | Stores Users, Teams, Projects, Tasks, Comments, Activity Log, Audit Log. GSIs on teamId and assigneeId |
| S3 (originals bucket) | Stores task image attachments uploaded by users. Old versions retained on update |
| S3 (resized bucket) | Stores thumbnails generated by the image-resize Lambda |
| Lambda — Image Resize | Triggered by S3 PUT events on the originals bucket. Writes thumbnails to the resized bucket |
| Lambda — Assignment Worker | Drains the SQS queue, writes activity logs, publishes CloudWatch custom metrics |
| Lambda — Daily Digest | Triggered by EventBridge at 9:00 AM. Scans tasks due today and sends digest emails via SNS |
| SNS | Fan-out for task-assignment events: notifies the assignee by email and feeds the SQS queue |
| SQS | Buffers assignment events for the worker Lambda. Decouples the API from background processing |
| EventBridge | Scheduled rule that triggers the daily digest Lambda every day at 9:00 AM |
| Cognito | User pool for sign-up/sign-in. Stores role and teamId as user attributes |
| CloudWatch | Custom metrics, dashboard (4 widgets), and alarms |
| IAM | Least-privilege roles for EC2, each Lambda, and the application identity |
| VPC + Subnets | Public subnets for the ALB; private subnets for EC2; NAT Gateway for outbound traffic |

## 🔔 Event-Driven Flow

When a manager assigns a task:

```
Backend (EC2) → SNS Topic
                    ├──→ Email notification to assignee
                    └──→ SQS Queue → Worker Lambda
                                          ├──→ Activity log saved to DynamoDB
                                          └──→ CloudWatch metric published (TasksAssigned)
```

Every day at 9:00 AM:

```
EventBridge → Daily Digest Lambda → Scans DynamoDB for tasks due today → SNS → Email digest
```

## 🚀 How to Run Locally

### Prerequisites
- Node.js v18+
- AWS credentials configured
- `.env` file set up (see below)

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
